### Micro-Tasks

Quick, simple jobs that do not require a full feature.

**Pricing:**
- Single task: £30
- Pack of 3: £75
- Pack of 5: £120

**What counts as a micro-task:**
- One small change
- A tiny adjustment in behaviour or layout
- A minor text, spacing, or visual change
- A fix that takes only a short, focused amount of time

**Examples:**

*Behaviour and Interaction:*
- Adjusting a button that does not respond properly
- Fixing a small layout issue, such as misaligned text
- Changing the time format, for example from '14:00' to '2:00pm'
- Ensuring names are capitalised correctly
- Changing the order in which items appear in a list

*Content and Appearance:*
- Updating titles or short messages in the app
- Adjusting colours or spacing
- Replacing a single image
- Tweaking the size of text for better readability

*Simple Fixes:*
- Fixing a small issue in a form (for example, a phone number box not accepting spaces)
- Fixing a dropdown that is not showing all options
- Correcting a button that currently leads to the wrong place

**NOT a micro-task:**
- New features
- Larger adjustments involving several parts of the app
- Changes that take more than a short, focused session
- Anything that needs a new section or multiple screens

**Process:** If a request is too large for a micro-task, Calmware will say so before starting and suggest the right Feature Ticket instead.

For any feature delivered, Calmware includes a 14-day bug warranty.

**Covers:**
- Fixes for issues caused directly by the new work delivered in a Feature Ticket
- Adjustments if the delivered feature does not match the agreed description

**Does NOT Cover:**

**After warranty:** After 14 days, fixes are handled as micro-tasks or as a new Feature Ticket.

## FAQ

**What is a Feature Ticket?**
A Feature Ticket is a clearly defined piece of work delivered at a fixed price. For example, adding an events section, a new profile area, or a simple referral flow.

**What is a micro-task?**
A micro-task is a quick, small fix or adjustment, such as correcting text, fixing a small layout problem, or changing how a single button behaves.

**How do I know which option I need?**
You describe what you want to change or add. Calmware will then suggest either a micro-task, a Small Feature Ticket, a Medium Feature Ticket, or a Large Feature Ticket based on the size of the work.
